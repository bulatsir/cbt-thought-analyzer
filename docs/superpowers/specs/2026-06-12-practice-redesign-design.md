# Редизайн практики Голосов: свободная фиксация + AI постфактум + обзор недели

**Дата:** 2026-06-12
**Репозитории:** `~/Projects/cogi_ios` (iOS) + `~/Projects/abc_app/backend` (FastAPI)
**Статус решений:** подход A и модель Sonnet 4.6 выбраны 2026-06-11; privacy-сдвиг подтверждён пользователем 2026-06-12.

## Проблема и обоснование

Боли (выяснены в брейншторме): в моменте дистресса тяжело категоризировать голос («это злобник? есть ли он вообще?») и ставить оценки; непонятно когда фиксировать; данные копятся без инсайтов; нет регулярности.

Терапевтическое обоснование: affect labeling (Либерман) — терапевтический эффект даёт само называние/вербализация, не таксономия и не цифры. Классификация в момент дистресса противоречит практике (префронтальная кора офлайн). Поэтому: в моменте — только свободный текст; категоризация — постфактум, как тренировка замечания, с AI-подсказкой. **AI подсказывает, но не решает.**

## Секция 1 — iOS: фиксация v2

### CaptureSheet v2

- Один сфокусированный `TextEditor` «Что в голове?» + кнопка **Готово**. Сохранение разрешено и с пустым текстом (зафиксировать «накрыло» без слов — тоже валидно).
- Чипы голосов — опциональны и свёрнуты (DisclosureGroup/кнопка «Голоса»), по умолчанию ничего не выбрано. Пре-селект из последнего момента убирается.
- **Оба слайдера удаляются полностью**: пер-голосовая интенсивность (0–10) и общий «Перегруз». Старые моменты с оценками продолжают декодироваться и отображаться в истории (read-only).

### Модель данных (`voices_state.json`, паттерн forward-compat Codable)

- `CompassionMoment.voices` — опционален, пустой список валиден.
- Новое поле `suggestion: MomentSuggestion?` (decodeIfPresent, default nil):

```swift
struct MomentSuggestion: Codable {
    var voiceID: UUID?            // кандидат из ростера, nil = AI не уверен
    var themes: [ThoughtTheme]    // из существующего enum (selfCriticism/threat/loss/injustice)
    var status: Status            // pending / confirmed / dismissed
}
```

- Старые поля рейтингов остаются в модели (decodeIfPresent) — не пишутся новыми моментами, читаются у старых.

### AI-подсказки

- После сохранения момента — асинхронный вызов `/suggest` (текст + имена голосов ростера + список тем). Пустой текст → запрос не шлём.
- Ответ → `suggestion` со статусом `pending`. Рендер в истории и MomentDetail: чипы с маркировкой AI (✨ / dashed border), тап = confirm (голос/тема применяется к моменту), крестик/свайп = dismiss. **Ничего не применяется автоматически.**
- Ошибка сети → suggestion просто отсутствует, момент полноценный без него. Без retry-UI в v1.

## Секция 2 — «Обзор недели» + бэкенд

### iOS

- На вкладке Голоса — карточка «Обзор недели» с кнопкой. По нажатию шлём последние моменты (текст + подтверждённые голоса/темы + даты) на `/review`.
- Результат (текст) кэшируется локально с датой генерации. Повторный запрос — не раньше чем через день (кнопка disabled с подписью).

### Бэкенд

- **Смена модели** в `backend/app/groq_client.py`: `MODEL = "anthropic/claude-sonnet-4.6"` (слаг проверить на openrouter.ai при реализации). Блок `provider: {order: [groq, sambanova-turbo]}` убрать — Claude эти провайдеры не отдают. `response_format: json_object` — проверить поддержку через OpenRouter для Anthropic; если нет, перейти на инструкцию в промпте + json-парсинг (уже есть). Смена затрагивает и существующий `/analyze`. Цена ~$5/мес на текущем профиле использования, латентность вырастет ~1с → 2–4с.
- **`POST /suggest`** — вход: `{text, voice_names: [str], language}`; выход: `{voice_name: str | null, themes: [str]}`. Имя голоса фильтруется server-side по присланному ростеру (паттерн как `_CANONICAL_NAMES_BY_LANG`), темы — по канонич. списку тем. Промпт в `prompts.py`.
- **`POST /review`** — вход: `{moments: [{text, voices, themes, date}], analyses?: [...], language}`; выход: `{review: str}` — синтез паттернов (какие голоса/темы повторяются, мягкое наблюдение, без диагнозов и советов «лечиться»). `max_tokens` побольше (~1024).
- Оба эндпоинта — тот же rate-limit по `X-Device-Id`, те же схемы pydantic в `schemas.py`.

### Privacy

Voices перестаёт быть local-only: текст моментов идёт бэк → OpenRouter → Anthropic. Подтверждено пользователем 2026-06-12 (личное использование, свой бэкенд, тот же путь, что уже проходят мысли из Анализа).

## Вне скоупа v1

- Напоминания/нотификации для регулярности.
- Voice-to-text ввод.
- Автоприменение подсказок, batch-подсказки для старых моментов.
- Хранение моментов на бэке (остаётся on-device).
- Редактирование текста момента после сохранения.

## Verification

1. `xcodebuild build` без warnings; бэкенд — локальный `uvicorn` + curl-прогоны `/suggest`, `/review`, `/analyze` (RU и EN).
2. Старый `voices_state.json` (с рейтингами, без `suggestion`) открывается без потерь; старые моменты показывают рейтинги read-only.
3. Новый момент: пустой текст сохраняется, запрос не шлётся; непустой → через ~секунды появляются ✨-чипы; confirm применяет, dismiss скрывает; офлайн → момент без подсказки, без ошибок UI.
4. Обзор недели: генерится, кэшируется, кнопка блокируется на день; перезапуск приложения не теряет кэш.
5. `/analyze` после смены модели: канонические имена искажений не дрейфуют (проверить пару RU/EN запросов, смотреть WARN-лог про dropped names).
