# Вкладка «Голоса» — практика самосострадания (iOS) — Design

**Дата:** 2026-06-01
**Клиент:** Cogi (iOS, SwiftUI), репозиторий `~/Projects/cogi_ios`, файл `Cogi/Cogi/ContentView.swift`

## Цель

Дать пользователю **за 3–5 секунд** зафиксировать момент, когда проснулся «внутренний голос»
(критик), чтобы тренировать автоматическое замечание. Механизм — КПТ self-monitoring +
экстернализация/дефузия (назвать критика как сущность: «Стыдобист», «Тревожник» — отделить
голос от себя). Главный принцип — **минимум трения**: чем меньше действий до записи, тем чаще
практика и быстрее формируется навык.

v1 — **чистая фиксация + просмотр истории**. Без AI, без бэкенда, без шага «ответа/рефрейма».

## Ключевые решения

| Параметр | Значение |
|---|---|
| Вкладка | Вторая, сразу после «Анализ» (порядок: Анализ → Голоса → Сохранено → Настройки). «Голоса» (EN «Voices»), SF Symbol `quote.bubble` |
| Сущность-голос | Пользовательская, CRUD в приложении: имя + эмодзи + цвет |
| Поток фиксации | Модальный `Sheet`: текст (опц.) → выбор голоса → 2 ползунка → «Готово» |
| Ползунок 1 | «Сила эмоции» 0–10 |
| Ползунок 2 | «Присутствие» 0–10 (0 захлёстывает → 10 на опоре, можешь применить навыки) |
| Текст мысли | Опционален (можно записать момент без слов) |
| Главный экран | Раскладка B: чипы-сводка + история + закреплённая кнопка «Зафиксировать» |
| Кнопки | Низ главного «＋ Зафиксировать» (открыть новую) · в листе «Готово» (сохранить) / «Отмена» |
| Хранение | Новый `VoicesStore`, файлы `voices.json` + `moments.json`, независимо от `entries.json` |
| AI/бэкенд | Нет (вне scope) |
| UI-kit | Только стандартный SwiftUI |

## Модель данных

```swift
struct InnerVoice: Codable, Identifiable, Hashable {
    let id: UUID
    var name: String
    var emoji: String        // 1 эмодзи; если пусто — фолбэк "🗣"
    var colorHex: String     // "#RRGGBB"
}

struct CompassionMoment: Codable, Identifiable {
    let id: UUID
    let createdAt: Date
    let voiceID: UUID        // ссылка для группировки/сводки-счётчиков
    // снимок голоса на момент записи — история целая при переименовании/удалении голоса
    let voiceName: String
    let voiceEmoji: String
    let voiceColorHex: String
    let text: String?        // опционально
    let emotion: Int         // 0–10
    let presence: Int      // 0–10 («Присутствие»)
}
```

**Снимок vs ссылка (решено — гибрид):** момент хранит и `voiceID`, и денормализованный снимок
(`voiceName/Emoji/ColorHex`). Отображение истории — из снимка (как `entries.json` хранит искажения
инлайн), поэтому переименование/смена цвета голоса влияет только на **будущие** записи, а прошлое
показывается «как было». Группировка и счётчики-сводка — по `voiceID`. Удаление голоса не рушит
историю: момент остаётся, рендерится из снимка.

## Хранение

```swift
@Observable @MainActor
final class VoicesStore {
    private(set) var voices: [InnerVoice] = []
    private(set) var moments: [CompassionMoment] = []   // сортировка: createdAt desc
    // voices.json + moments.json в URL.documentsDirectory
    // паттерн EntryStore: makeCoder() (.iso8601, .prettyPrinted, .sortedKeys),
    // load()/persist() через Task.detached, write(options:[.atomic])
}
```

- Создаётся в `ContentView` как `@State`, прокидывается `.environment(store)` (как `EntryStore`).
- Загрузка в `ContentView.task` рядом с `store.load()`.
- Полностью независимо от `entries.json` — анализ мыслей не затрагивается.

## Экраны

### Главный (`VoicesView`, раскладка B)
- Заголовок «Голоса».
- **Ряд чипов-сводки** по голосам ростера: `эмодзи имя · N` (N = число моментов с этим
  `voiceID`), фон/контур — цвет голоса. Тап по чипу → редактор голоса. Это и есть «видеть паттерны».
- **История** (`List` или `ScrollView`): строки моментов, цветная полоска слева = цвет голоса
  (из снимка). В строке: сниппет текста (или «без слов» курсивом), мета `эмодзи имя · эмоция N ·
  присутствие M · relative-дата`. Свайп-делит (как «Сохранено», `allowsFullSwipe: false`).
- Внизу закреплена кнопка **«＋ Зафиксировать»** (`.safeAreaInset(edge: .bottom)` или overlay) —
  открывает лист фиксации.
- Пустые состояния: нет голосов → подсказка «Создай первый голос» (кнопка открывает редактор
  нового голоса); есть голоса, нет моментов → лёгкая подсказка зафиксировать первый.

### Лист фиксации (`CaptureSheet`, модальный)
- `Sheet` с `NavigationStack`: слева «Отмена», справа «Готово» (сохранить).
- `TextEditor` «Что произошло / какая мысль» — опционально.
- **Выбор голоса**: ряд чипов-кнопок (горизонтальный, `WrapLayout` уже есть в проекте),
  выбранный подсвечен своим цветом; «＋» в ряду открывает редактор нового голоса инлайн.
- `Slider` «Сила эмоции», шаг 1, диапазон 0…10, дефолт 5; рядом значение.
- `Slider` «Присутствие», шаг 1, 0…10, дефолт 5; подпись «0 захлёстывает → 10 на опоре».
- **Сохранение**: «Готово» активно только когда выбран голос (текст и ползунки не обязательны —
  у ползунков есть дефолт). Если голосов ещё нет — ряд показывает только «＋», и до создания
  первого голоса сохранить нельзя.

### Редактор голоса (`VoiceEditor`, модальный/пуш)
- `TextField` имя.
- `TextField` для эмодзи (1 символ; стандартная клавиатура с эмодзи).
- `ColorPicker` цвет.
- Удаление существующего голоса (с `confirmationDialog`): голос убирается из ростера; его моменты
  в истории остаются (снимок), но чип-сводка для него пропадает.

### Детали момента (`MomentDetail`)
- Просмотр: голос (снимок), текст, эмоция, присутствие, дата. Удаление момента.

## Локализация
- Чрома (заголовки вкладки, лейблы полей/ползунков, кнопки) — через существующий `enum L10n`
  (RU/EN). Новые ключи: `tabVoices`, `captureTitle`, `fieldThought`, `fieldVoice`,
  `sliderEmotion`, `sliderPresence`, `presenceHint`, `newVoice`, `voiceName`, `voiceEmoji`,
  `voiceColor`, `deleteVoice`, `capture`, `noWords`, empty-state строки.
- Имена голосов — пользовательские, **не** локализуются.

## Вспомогательное
- `Color(hex:)` / `Color.toHex()` — маленький helper для `colorHex` (стандартный SwiftUI `Color`).
- Хаптика на сохранение момента — по желанию, как в `AnalyzeView` (паттерн `lastSavedId`).

## Вне scope v1
AI-анализ момента; шаг сострадательного ответа/рефрейма; «добрый контр-голос» у сущности;
напоминания/виджеты; графики динамики эмоции/присутствия во времени; экспорт. Только фиксация +
история + счётчики-сводка.

## Архитектурные заметки (консистентность с существующим кодом)
- Файл один — `ContentView.swift` (конвенцию не ломаем), новые типы/вью добавляются туда же.
- TabView в `ContentView` получает новую вкладку **вторым** элементом (между «Анализ» и
  «Сохранено»); tab label читает `settings.language` прямо в `body` (как у остальных — иначе
  теряется @Observable-tracking).
- Паттерн стора и Codable-бэккомпата — копируем у `EntryStore`/`SavedThought` (новые файлы, но
  на будущее: декодим списки терпимо к пустому/битому файлу → `[]`).
